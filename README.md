# Project Performance Dashboard

An interactive **Project Performance Dashboard** built to monitor project health, track task progress, and generate actionable insights for data-driven decision-making.

The dashboard provides a centralized view of multiple projects, helping stakeholders identify performance trends, detect risks early, and improve overall operational efficiency.

---

## Features

### Project Overview
- Track **50 total projects**
- Monitor **4,826 total tasks**
- View overall completion performance

### Task Performance Metrics
Tasks are categorized into:
- Passed
- Pending
- Deferred
- Cancelled

### Performance Distribution
Visual breakdown of project performance:
- Excellent
- Good
- Average
- Poor

### Status Insights
Identify task progress using:
- On Track
- Needs Attention
- Delayed
- Critical

### Interactive Filters
Dynamic filtering options:
- Project Name
- Target Date
- Performance Status

### Completion Monitoring
- Overall completion percentage
- Timeline-based tracking
- Performance trend visibility
